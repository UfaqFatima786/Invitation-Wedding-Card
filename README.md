# 💍 Wedding Invitation Card

A beautiful and interactive **Wedding Invitation Card Website** built with React.js. This project presents a modern digital wedding invitation experience with elegant animations and a musical touch.

## ✨ Features

- 💌 Digital Wedding Invitation Card
- 🎨 Elegant and attractive user interface
- 🎵 Background music integration
- ✨ Smooth animations and transitions
- 📱 Responsive design
- ⚛️ Component-based React architecture
- 🎬 Interactive animations using Framer Motion

## 🛠️ Technologies Used

- **React.js** – Building interactive UI components
- **Vite** – Fast development and build tool
- **JavaScript (ES6+)** – Application functionality
- **CSS3** – Styling and layout
- **Framer Motion** – Smooth animations
- **HTML5** – Web structure


## 📌 Project Purpose

This project was created to practice React.js, component-based development, responsive UI design, animation techniques, and building interactive frontend experiences.
